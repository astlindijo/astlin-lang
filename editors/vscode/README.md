# Astlin syntax support

Open this folder in VS Code and use **Run → Start Debugging** with the extension host
configuration to preview `.ad` highlighting. Alternatively, copy this folder into
your VS Code extensions directory and restart the editor. No extension code executes;
the extension contributes a language grammar and bracket/comment configuration.

This provides syntax highlighting, bracket pairs, and line comments. Semantic
completion, diagnostics, formatting, and debugging require future language-server work.
