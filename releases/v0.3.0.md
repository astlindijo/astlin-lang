# Astlin v0.3.0 — AI toolkit

Copyright © 2026 Astlin Dijo. MIT license. Experimental development version.

This update adds native building blocks for AI application development:

- First-class immutable JSON values and garbage-collected nested data.
- Optional libcurl HTTP, environment-based configuration, deadlines, TLS verification,
  bounded responses, and structured client results.
- OpenAI-compatible non-streaming chat and batched embedding clients, usable with
  configured hosted endpoints or compatible local model servers.
- Overlapping Unicode character chunking, exact cosine retrieval, offline BM25,
  model-tagged index persistence, source selection, and grounded prompt construction.
- CPU float64 vector math, stable softmax/top-k, and matrix multiplication.
- `init --template rag|llm`, `doctor --ai`, examples, and local mock-provider tests.

See `AI.md` for runnable workflows and exact limitations. No paid provider calls
are needed for the tests. Model weights and API credentials are not included.

This is an AI application toolkit, not a GPU training framework. There is no native
autograd, CUDA/Metal backend, tokenizer, ANN database, async runtime, or streamed chat
implementation in this version. Retrieval quality depends on the data and embedding
model; citations and prompt instructions do not guarantee factuality or injection resistance.

Download the versioned wheel and install it with Python 3.10+. Clang or GCC is needed
for native builds; programs importing HTTP/LLM modules additionally need libcurl headers
and libraries at build time and the linked libcurl at execution time. Pure JSON/vector/
offline RAG programs do not require libcurl.
