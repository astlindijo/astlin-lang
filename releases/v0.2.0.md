# Astlin v0.2.0

Astlin is an experimental programming language with `.ad` source files, static type
checking, automatic garbage collection, and compilation to native executables through C.

This development release includes:

- Typed functions, recursion, inferred locals, immutable bindings, loops, and checked integers.
- Multi-file imports with aliases and immutable, nominally typed structs.
- Unicode strings, scalar lists, list/string operations, file I/O, arguments, and math.
- A tracing collector with compiler-managed roots and explicit heap diagnostics.
- Project initialization, native test execution, source diagnostics, and toolchain checks.
- Offline-installable Python distributions and VS Code syntax support.

## Install

Download the wheel attached to this release, then run:

```sh
python3 -m pip install ./astlin_lang-0.2.0-py3-none-any.whl
astlin doctor
astlin init hello-astlin
cd hello-astlin
astlin run
```

Python 3.10+ and Clang or GCC are required to compile/run `.ad` programs. Compiled
programs run without Python. The source archive contains the compiler, runtime,
standard library, examples, tests, and language reference.

## Verification

`SHA256SUMS` lists SHA-256 hashes for the wheel and source archive. Verify downloaded
artifacts with `shasum -a 256 -c SHA256SUMS` on macOS or `sha256sum -c SHA256SUMS` on Linux.

Local release validation covers compiler/native integration tests, isolated offline
installation of both distributions, and garbage-collection stress programs under
address and undefined-behavior sanitizers. Validation has been performed on macOS ARM64;
the repository's CI configuration additionally targets Ubuntu and supported Python versions.

## Maturity

Astlin is experimental. Syntax/API compatibility is not guaranteed, and performance
superiority over established languages has not been demonstrated. The collector is
single-threaded; lists are copied by update operations. Concurrency, a language server,
debugger integration, and a language package registry are future work.

See `LANGUAGE.md` for exact semantics and `CHANGELOG.md` for implementation changes.
